# 接手这个个人知识库

先读「00 关于我/从这里开始」。相关任务才打开对应材料。在用户已启用持续记录的会话中，工作、学习、生活的实质讨论由本地助手按项目或课题留存。保留双方发言、日期和来源，分别标出本人的考虑、明确决定及模型回应。指定“这段别记”的内容不要写入。批量迁移先用 preview 列出范围。长期画像、修改旧文、发布和跨服务传送均须单独授权。

有本机权限的助手按上一级 README 运行本地工具。用 category 和 topic 将新对话接入同一主题，必要时主动推断主题并核对既有名称。不确定时保留在库外收件箱。无本地权限时提供 README 中格式的 Markdown，让用户保存到约定收件箱。找回决定时打开主题索引，点回原话；不要把模型建议写成本人决定。用户批注写在“我的批注”区，自动记录区会由工具维护。
